# 🌌 ANIMUS ENGINE V2: Premium Web Design Suite

An ultra-premium, AI-driven interactive website creation and diagnostics workspace. Built to match Viktor Oddy's state-of-the-art visual coding workflows, powered by Kimi K2.6's multimodal agentic swarm architecture and certified by the Animus Sentry Quality Auditor.

---

## 🚀 Key Features

*   **Vibe-Coding Console**: Type natural language prompts and compile premium, motion-heavy websites client-side instantly.
*   **Aether Presets System**: Seamlessly switch between curated, rich HSL gradient modes (Solaris Flare, Obsidian Void, Cyber Grid, Organic Wave) that alter theme accents, fonts, and geometry.
*   **WebGL Three.js Core**: Procedural 3D mesh vectors floating in the background, responding to user pointer mouse movements in real-time.
*   **GSAP Scrollytelling Column**: Smooth, parallax-triggered timeline cards revealing step-by-step product narratives dynamically.
*   **Responsive Viewport Frame**: Toggle between physical device shells (Desktop monitor, Tablet screen, Smartphone view) to preview responsive layouts instantly.
*   **Animus Sentry Auditor**: Automated WCAG contrast ratio calculations, structural HTML z-index balances, and div tag completeness checks with logs showing found critiques and automatic self-corrections.
*   **Code Export Terminal**: High-fidelity side-by-side terminal with tabbed components (HTML, CSS, JS), copy to clipboard, and one-click ZIP bundle downloads.

---

## 🛠️ Tech Stack & Components

1.  **Framework**: React (Vite-scaffolded, compiled for production in under 700ms).
2.  **Design System**: Custom CSS HSL variables, neon drops, and glassmorphic panels.
3.  **Animations**: Built-in GSAP ScrollTrigger timeline bindings.
4.  **3D Layer**: WebGL Canvas rendering powered by Three.js.
5.  **Interactivity**: Lucide-React icon packs, canvas-confetti compile cues.

## 💻 Local Deployment

To launch the premium workspace on your local machine:

1.  **Navigate into the directory**:
    ```bash
    cd /Users/macbook/.gemini/antigravity/scratch/animus_engine_v2
    ```
2.  **Run Development Server**:
    ```bash
    npm run dev
    ```
3.  **Open in Browser**:
    Visit `http://localhost:5173/` and experience the magic.

4.  **Compile Production Build**:
    ```bash
    npm run build
    ```

## 📤 Push to your GitHub Repository

To host and deploy this repository on your GitHub account, run the following commands in your shell:

1.  **Create a new public/private repository on GitHub**:
    *   Go to [github.com/new](https://github.com/new) and name it `animus_engine_v2`.
    *   *Do not* initialize it with a README, license, or gitignore (we already created premium ones for you!).

2.  **Link your local repository and push**:
    ```bash
    # Add your GitHub remote origin link
    git remote add origin https://github.com/YOUR_GITHUB_USERNAME/animus_engine_v2.git
    
    # Rename default branch to main
    git branch -M main
    
    # Push the initial commit to your repository
    git push -u origin main
    ```
